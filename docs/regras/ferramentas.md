# Escolha de ferramentas

Toda escolha de ferramenta, biblioteca ou serviço:
- compara **pelo menos 3 opções**;
- inclui entre elas o que o dono **já paga** ou já tem instalado, quando houver algo aplicável;
- informa o **custo** de cada opção (licença, assinatura, cota, custo de manutenção);
- termina com recomendação e motivo.

Exemplos dados pelo dono são ponto de partida, nunca lista fechada: procure além deles.

Registre a comparação no ADR (`docs/decisions/NNNN-slug.md`).
