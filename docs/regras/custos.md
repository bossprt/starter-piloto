# Custos

Projeto **comercial** (`comercial: sim` em `docs/PRODUCT.md`) exige, antes de construir,
um documento com fontes e data contendo:
- custo de construir;
- custo mensal de manter (infraestrutura, serviços, assinaturas);
- preço;
- margem;
- ponto de equilíbrio.

Projeto **não comercial** (`comercial: não`) fica dispensado desta regra.
Se o projeto mudar para comercial, isso é decisão de direção (ver `direcao.md`).
